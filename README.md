# แดชบอร์ดค่าน้ำมัน

แดชบอร์ดสำหรับบันทึกและติดตามค่าใช้จ่ายน้ำมันรถ เป็นเว็บแอปแบบ static ล้วน (ไม่ต้องติดตั้ง dependency ใด ๆ)

## ใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้โดยตรง หรือรันเซิร์ฟเวอร์ static ง่าย ๆ เช่น

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## ฟีเจอร์

- เพิ่ม/แก้ไข/ลบรายการเติมน้ำมัน (วันที่ รถ ปั๊ม ลิตร ราคา/ลิตร เลขไมล์ หมายเหตุ)
- สรุปยอดใช้จ่ายรวม ปริมาณน้ำมันรวม ราคาเฉลี่ยต่อลิตร และอัตราสิ้นเปลืองเฉลี่ย (กม./ลิตร)
- เปรียบเทียบค่าใช้จ่ายเดือนนี้กับเดือนก่อน
- กราฟค่าใช้จ่ายรายเดือนและราคาน้ำมันเฉลี่ยต่อลิตรตามเวลา พร้อมกราฟเปรียบเทียบค่าใช้จ่ายแยกตามรถ (เมื่อมีมากกว่า 1 คัน)
- กรองข้อมูลตามช่วงเวลาและตามรถ
- ส่งออกข้อมูลเป็นไฟล์ CSV
- รองรับโหมดมืด/สว่าง
- บันทึกข้อมูลไว้ใน `localStorage` ของเบราว์เซอร์ (ไม่มีการส่งข้อมูลออกไปที่เซิร์ฟเวอร์ใด ๆ)

## โครงสร้างไฟล์

- `index.html` — โครงหน้าเว็บ
- `style.css` — ดีไซน์และธีม (รองรับ light/dark)
- `app.js` — ตรรกะจัดการข้อมูล การกรอง สถิติ และกราฟ (ใช้ [Chart.js](https://www.chartjs.org/) ผ่าน CDN)
